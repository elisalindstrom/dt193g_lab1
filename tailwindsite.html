Tailwind

Tailwind är ett CSS-ramverk som gör det möjligt att skriva klasser direkt vid elementen i HTML-koden, det är ett så kallat utility-first-ramverk. Mer information om ramverket finns på Tailwinds webbplats.

Min upplevelse

Det var hyfsat enkelt att komma igång med Tailwind, särskilt efter att tillägget Tailwind CSS IntelliSense installerats i Visual Studio Code. Tillägget hjälper till med klassnamn och gör det enklare att både lära sig och hitta rätt bland namnen. Till en början var det svårt att veta vilka klasser som skulle användas till vad. Nackdelen jag upplevt är också att det kan bli lite rörigt i HTML-koden, som jag vanligtvis brukar hålla ganska stilren.
